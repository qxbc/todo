
# TODO App

Простое веб-приложение для управления задачами. Позволяет пользователям добавлять, редактировать, удалять и отмечать задачи как выполненные.

## Функционал

- **Добавление задач** – создайте новую задачу.
- **Редактирование задач** – изменяйте детали задач.
- **Удаление задач** – удаляйте ненужные задачи.
- **Пометка как выполненные** – отмечайте завершенные задачи.
- **Сохранение в браузере** – задачи сохраняются локально.

## Стек технологий

- **Frontend**: React.js, TailwindCSS
- **Сборка**: Create React App

## Установка и запуск

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/qxbc/todo.git
   ```

2. Установите зависимости:

   ```bash
   npm install
   ```

3. Запустите проект:

   ```bash
   npm start
   ```

4. Откройте [http://localhost:3000](http://localhost:3000) для доступа к приложению.
